# 20 - クールダウンワークアウトクロック

**ビルド日**: 2026-11-03
**カテゴリ**: practical
**slug**: cool-down-workout-clock

## 概要
運動後の各ストレッチポーズをタイマーで順番ガイドするアプリ。デフォルト8種目のルーティンをベースに、種目の追加・削除・並べ替えで自分だけのルーティンを作成できる。

## 機能
- デフォルト8種目クールダウンルーティン（大腿四頭筋〜深呼吸まで）
- 種目の追加・削除・上下並べ替え
- 大型カウントダウン表示（現在の種目名・残秒数）
- 種目ごとのプログレスバー
- 全体の経過時間プログレスバー
- 次の種目への自動移行（Web Audio APIビープ音・残り3秒カウントダウン音）
- 開始/一時停止/リセット制御
- カスタムルーティンをlocalStorageで保存・読込
